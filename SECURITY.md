# Security Policy

This repository contains prompts, standards and a small guardrail hook. It must never contain secrets or confidential Infinium information.

If you find a secret, confidential detail, or a way the agents or hook could be abused:

1. **Do not open a public issue.**
2. Report it to `TODO(infinium): security contact or channel`.
3. If a credential was exposed, it must be rotated immediately, regardless of how quickly it was removed.

---
description: Create a new Architecture Decision Record from Infinium's template
argument-hint: <decision title>
---

Create a new ADR in `docs/adr/` for: $ARGUMENTS

Number it one higher than the highest existing ADR (start at 0001), use a kebab-case file name, and follow the Infinium ADR format (Architecture Guide §2): Title, Status (Proposed), Date, Context, Decision, Options considered (with pros and cons), Consequences. Use the `architect` agent to fill it in from the codebase and conversation; leave clearly marked questions where information is missing.
